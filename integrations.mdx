## Discord Notifications

Configure Discord in **Integrations → Discord** as a separate integration from generic Webhooks. Connect a Discord channel by creating a Discord webhook, then add its URL in Bragly. Bragly verifies the URL before connecting it.

### Notification types

Discord supports notifications for:

- **Form submissions:** Receive notifications when someone submits a form. Limit these notifications to selected forms.
- **Autosynced reviews:** Receive notifications when reviews are autosynced.
- **Deleted reviews:** Receive notifications when reviews are deleted. This notification is off for new connections.

New connections enable form submissions and Autosync notifications by default. Autosync and multi-review deletion operations send one batch summary, while deleting one review sends an individual message.

### Customize messages

Customize the message and embed for each event, then preview the result before saving. **Send Test Message** sends the current unsaved design, so you can verify changes before applying them.

If a Discord webhook becomes disconnected, reconnect it with a replacement URL. Bragly retains the existing configuration when you replace the URL.

<Callout kind="info">
Discord is available only on plans with Webhooks access.
</Callout>

## Shopify Billing and Review Requests

For teams with an active Shopify connection, billing is managed through the Shopify App Store. The Bragly billing page shows your current plan and directs you to Shopify admin to change your plan, upgrade, downgrade, or cancel.

If your team's plan does not include review collection, Bragly does not email customers after an order. The Shopify integration page shows **Upgrade to Send Review Requests** with a **View Plans** action.

## API Endpoints

Bragly's REST API lets you manage docs programmatically. Base URL: `https://api.example.com/v1`.

### Create a Document

<Request tabs="JavaScript,cURL" show-lines="true">
  ```javascript
  const response = await fetch('https://api.example.com/v1/docs', {
    method: 'POST',
    headers: {
      'Authorization': `Bearer ${YOUR_API_KEY}`,
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({
      title: 'New Doc',
      content: 'Hello from API'
    })
  });
  ```
  ```bash
  curl -X POST https://api.example.com/v1/docs \
    -H "Authorization: Bearer YOUR_API_KEY" \
    -H "Content-Type: application/json" \
    -d '{"title":"New Doc","content":"Hello from API"}'
  ```
</Request>

<Response tabs="200">
  ```json
  {
    "id": "doc_123abc",
    "title": "New Doc",
    "content": "Hello from API",
    "created_at": "2024-10-15T10:00:00Z"
  }
  ```
</Response>

<ParamField path="title" param-type="string" required="true">
  Document title, max 255 characters.
</ParamField>

<ParamField body="content" param-type="string" required="true">
  Markdown content for the document.
</ParamField>

<ParamField header="Authorization" param-type="string" required="true">
  Bearer token obtained from your API settings.
</ParamField>

## Webhooks for Automation

Set up webhooks to receive events like doc publishes. Configure the webhook URL in project settings.

```mermaid
sequenceDiagram
    Bragly->>+YourServer: POST /webhook
    YourServer-->>-Bragly: 200 OK
```

Handle incoming payloads with this example:

<CodeGroup tabs="Node.js,Python">
  ```javascript
  app.post('/webhook', (req, res) => {
    const event = req.headers['x-bragly-event'];
    const payload = req.body;
    
    if (event === 'doc.published') {
      console.log('Doc published:', payload.doc_id);
      // Trigger your automation
    }
    
    res.status(200).send('OK');
  });
  ```
  ```python
  from flask import Flask, request
  
  app = Flask(__name__)
  
  @app.route('/webhook', methods=['POST'])
  def webhook():
      event = request.headers.get('X-Bragly-Event')
      payload = request.json
      
      if event == 'doc.published':
          print(f"Doc published: {payload['doc_id']}")
          # Trigger automation
      
      return 'OK', 200
  ```
</CodeGroup>
